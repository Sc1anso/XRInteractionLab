### Quest test update — Distance Hand Grab (2026-11-04)
Instructor-confirmed: left and right bare-hand targeting, pull, movement and release work; target selection has a finite range. The test used Pinch. The target's current Supported Grab Types value is 3 (Pinch + Palm), so Palm is available in static setup but not yet runtime-tested. To change the accepted type, select the target child ISDK_DistanceHandGrabInteraction, edit the DistanceHandGrabInteractable Supported Grab Types setting in Inspector, and choose Pinch, Palm, or both; do not rerun the Quick Action on the configured object. Custom gesture recognition requires a separate recognition setup and is not a simple replacement for this grab-type setting. The capsule may be scaled down for comfort; keep its collider aligned with its visible mesh and retest targeting after resizing.
